# AI自動化程式工作術：從想法、程式到實用小工具

## AI 輔助寫程式的正確觀念

### AI-assisted Coding 與 Vibe Coding

AI-assisted Coding（AI 輔助寫程式）把 AI 當工具：人定義問題、檢查程式、負責驗收。Vibe Coding 比較像用自然語言與 AI 一起探索，快速嘗試介面與創意。

兩者都能用，但用途不同：

| 情況                     | 建議方式                       |
| ------------------------ | ------------------------------ |
| 公司正式報表、金額、個資 | AI 輔助，人員逐段檢查          |
| 課堂原型、創意小工具     | 可先 Vibe Coding 快速試作      |
| 程式要長期維護           | 匯出程式、版本控制、測試與文件 |
| 一次性的畫面概念         | 可先用 Canvas／AI Studio 預覽  |

生成式 AI 可能產生不存在的函式、過時介面、錯誤路徑或看似合理的分析結論。這叫做生成錯誤或幻覺風險。不是因為 AI「故意說謊」，而是它在生成最可能的文字與程式，不是替你完成所有事實查核。

## Gemini Canvas 生成 Python 程式，使用Canvas生成

Canvas 適合在同一個畫面中一邊對話、一邊查看與修改文件、程式或 App。操作入口可能因帳號與介面更新而不同；原則是：在 Gemini 網頁版開啟 Canvas，描述需求，等待程式或 App 生成，再以後續提示修改。

Python 程式可從 Canvas 匯出至 Colab。若介面沒有「匯出至 Colab」，可複製程式到新的 Colab Notebook；公司或學校帳號可能受管理政策限制。

```text
### 先生成教材內容
我想要訓練客服新人知道「要有禮貌」，但遇到延遲、瑕疵或錯寄時仍不知道怎麼回。
請先幫我見立一份針對這件事的練習文件
```

## 實例：今天吃什麼轉盤

### 需求拆解

輸入餐廳或食物選項，設定預算與飲食偏好後轉動轉盤。支援重新抽選、排除結果及保存近期用餐紀錄。

### 提示詞

```text
請建立一個「今天吃什麼轉盤」網頁。

功能需求：
1. 使用者可以輸入餐廳名稱或食物，加入候選清單。
2. 提供便當、麵食、火鍋、速食及自助餐等預設選項。
3. 可以刪除單一選項或清除全部選項。
4. 重複或空白的內容不能加入。
5. 提供預算、用餐方式及飲食偏好篩選。
6. 至少有兩個選項才能啟動轉盤。
7. 按下「開始抽選」後，轉盤快速旋轉並逐漸停止。
8. 抽選完成後，清楚顯示抽中的餐廳或食物。
9. 提供「就吃這個」「再抽一次」及「今天不想吃」按鈕。
10. 選擇「今天不想吃」後，暫時排除該選項並重新抽選。
11. 保存最近10筆用餐紀錄，包含日期與抽選結果。
12. 使用瀏覽器本機儲存，重新整理後仍保留選項及紀錄。

畫面設計：
- 桌面版左側顯示選項設定，中間顯示大型轉盤，右側顯示結果與最近紀錄。
- 手機版改為單欄排列。
- 使用米白色背景，搭配橘色、黃色及紅色。
- 卡片採用圓角及柔和陰影。
- 轉盤要有流暢動畫，指針必須正確對應抽選結果。
- 所有按鈕與功能都要能實際操作，不要只製作靜態畫面。

初次開啟時加入雞腿便當、牛肉麵、火鍋、咖哩飯、水餃、義大利麵、自助餐及漢堡作為測試資料。
- 介面使用繁體中文、手機與電腦皆可閱讀。
- 下面要放著作聲明：Copyright © 2026 Wei-CHeng Chen. All Rights Reserved.
- 程式碼使用繁體中文註解，並在程式前用 5 點說明設計思路。
```
